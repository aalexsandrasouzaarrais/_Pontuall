# Employer WorkShift - Portal do Colaborador (Módulo Standalone)

Este projeto contém exclusivamente a interface e funcionalidades do **Portal do Colaborador** do sistema de Gestão de Escalas e Ponto Digital da Employer.

## 🚀 Funcionalidades Inclusas
- ⏱️ **Ponto Digital com GPS**: Registro de presença com validação de geolocalização e horário.
- 📅 **Calendário Detalhado**: Visualização mensal e semanal dos turnos de trabalho, reuniões e plantões.
- 📊 **Carga Horária & Assiduidade**: Acompanhamento em tempo real da meta semanal de horas trabalhadas e faltas/justificativas.
- 🔄 **Solicitações de Folga e Troca de Turno**: Envio de pedidos de troca com colegas ou folgas compensatórias.
- 📄 **Envio de Atestados & Justificativas**: Upload e envio de atestados médicos e declarações.
- 💬 **Chat da Equipe**: Canal de comunicação ao vivo com a liderança e colegas.
- 🔔 **Central de Notificações**: Alertas em tempo real sobre escalas e avisos da gestão.

---

## 🛠️ Como Executar o Projeto

1. **Instalar as dependências:**
   ```bash
   npm install
   ```

2. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

3. **Gerar a versão de produção (Build):**
   ```bash
   npm run build
   ```
